# agents-skills

My personal, project-agnostic Claude Code Skills. This repo IS meant to be
cloned/synced directly as `~/.claude/skills/` (the global skills folder) —
skill folders live at the root of this repo, not nested under `.claude/skills/`.

## Skills
- `discovery/` — turns a vague project idea into a Spec draft via guided questions.
- `discovery-feature/` — same, scoped to a new feature within an existing project
  (aware of the project's own CLAUDE.md).
